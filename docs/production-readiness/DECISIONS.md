# Production-readiness decision log

Use this file for approved choices that affect multiple workstreams or materially change product scope. Do not use it as a meeting transcript. Link each decision to its evidence and affected roadmap tasks.

## Status values

- **Proposed:** awaiting the named approver.
- **Accepted:** approved and authoritative for implementation.
- **Superseded:** replaced by a later decision; keep the original for traceability.
- **Rejected:** considered but not chosen.
